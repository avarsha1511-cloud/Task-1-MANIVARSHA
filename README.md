# Titanic Data Science Project

## Project Overview

This project was completed as part of the Decode Labs Data Science Internship. The project focuses on understanding, cleaning, analyzing, visualizing, and building a predictive model using the Titanic dataset.

## Tasks Completed

* Task 1: Data Collection & Dataset Understanding
* Task 2: Data Cleaning & Preprocessing
* Task 3: Exploratory Data Analysis (EDA)
* Task 4: Data Visualization
* Task 5: Predictive Model

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Project Features

* Data preprocessing
* Missing value handling
* Exploratory Data Analysis
* Graphical visualizations
* Logistic Regression model
* Survival prediction

## Dataset

Titanic Dataset from Kaggle
